# Security policy

Please report security issues privately through GitHub's **Report a
vulnerability** flow on this repository. Do not open a public issue for a
vulnerability.

Include the affected version, a minimal reproduction, and the impact you
believe it has. You should receive an acknowledgement within a few days.

## Scope

This plugin reads public OpenCode documentation over HTTPS and stores a policy
cache in OpenCode plugin storage. It does not read credentials, prompts, or
session content. Reports about the OpenCode host, npm, or provider
infrastructure should go to the relevant project.
